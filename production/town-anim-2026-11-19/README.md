## 底子 + 特效合成（1:1，832×275）

`base-p{1,2,4}-p{0,2,4}.png`：静态底图 + 当期特效层。p1 = 7 旗 + 2 火把 + 4 路灯 + 喷泉；
p2 另加 2 篝火、p4 另加 2 水晶。三个相位并排能看出旗面角度、灯火明暗、水花的差别。

## 看这些图时该问的问题

1. 旗杆**是不是站在屋顶上**？（旧版 8 座悬空 —— 闸门量不到，只能看）
2. 烟是**一缕**还是**几个点**？（等距相位会让烟"原地蹦"，见 `smoke-closeup-x8.png`）
3. 水车是**在转**还是**整只在挪**？（轮毂 2×2 八帧必须逐像素相同）
4. 半透明的东西**有没有被墨线圈住**？（烟区墨色像素必须为 0，负向臂 423）
