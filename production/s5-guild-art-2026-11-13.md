## 2. 图放哪里：卡片放不下，改到描述浮层（实测）

第一版把 44×44 塔图塞进建筑卡左栏。真机 844×390 实测：

```
.bcard 宽 179px（P1 定死 4 列 × 2 行，注释写明"仍放得下建造按钮与最长状态行"）
44px 图 + 8px gap ⇒ 文本列只剩 ~118px
⇒ 建筑名截断成「魔法…」、"建造"按钮折成两行（真机实测，已废弃该版）
```

CSS 里 P1 那段注释早就写了这个预算（"卡宽 179px 仍放得下…"），是我先改再量。
第二版改到**建筑描述浮层**（`.bdesc`，D-70 为描述加的 absolute 层，不参与布局）：

```
实测 844×390：.bgrid 736px / .town-pane 756px ⇒ **横向不溢出**
              .bs 被裁切 0 张；浮层 740×60，图 44×44 在文首左侧
```

代价要说清楚：**塔图要点一下建筑名才看得到**。这是"卡片预算"与"外形可见性"之间
当下能取的最优解；等 plot 场景真做出来，这批图直接搬过去，不用重画。

## 3. 三阶的定义（§6.3 逐条落地）

| 档 | 建筑 | 必须有的那一笔 | 怎么变成可量的 |
|---|---|---|---|
| 1 | `guild1` 石塔 | 方塔 + 木门 | 连通块 = **1**（不许有飘浮件）+ 木门色 ≥24px |
| 2 | `guild2` 尖顶塔 | 尖顶 + 悬浮符文 | 顶点 ≤4px 且**往下 5 行行宽翻倍**（真三角）+ **2 枚**离体块 ≥8px |
| 3 | `guild3` 浮空塔 | 基座离地 + 环 | 塔身与基座之间**整行透空 ≥3 行** + 环高 ≥8 行、宽 ≥ 塔身 1.15× |

四族只换材质（草坡石木 / 熔岩黑铁 / 枝干木构 / 浮空白石），**结构逐像素相同** ——
这一条由 `[G5]` 的 alpha 掩码比对保证，不是靠"看着一样"。

四条负向对照都是"真实会犯的错"，不是随便改坏一个数：
`flat` = 画成同一张（S5 要防的原始 bug）；`noFloat` = 基座贴地（"浮空"没了）；
`noRune` = 中间档没有识别点；`noSpire` = 方塔/尖顶两档塌成一档。

## 5. 目检（铁律 1：×8 单张，不看缩略图）

`art/p1..p4_L1..L3.png`（×8）。结论与踩过的坑：

- **L2 的符文必须是菱形**：3×3 方块在这套美术里已经是"窗/砖"的母题，转 45° 才读成"悬浮符文"。
- **L3 的环在 44px 里画不"干净"**，四版实拍：
  ① 塔身外两段弧 → 一对括号；② 横平带 → 一块横板；③ 中间低两头上翘 → 下垂的绳子；
  ④ 外端尖内端厚 → 两只箭头。**只有闭合椭圆**读得出"圈"。
- 闭合椭圆**必须画在描边之后**：44px 内它必然贴着塔身，走描边就会被墨线焊进墙里，
  左右各留一团黑疙瘩（第五版实拍）。魔法环是光，不是构件。
- L3 环的左右两端仍各剩一个小"眼"（1px 曲线的墨环切点）。**接受**：1× 卡片尺寸下读不出，
  ×8 才看得见。要彻底消掉得把画布拉到 60px 以上，那就不是"卡片缩略图"这件东西了。
- p2（熔岩黑铁）的木门与墙明度接近，是四族里最糊的一处；仍在"能认出有门"的边界内，
  记为**已知弱项**。

## 6. 仍欠（都在本批之外）

1. **市场 / 兵营两条链没有外形** —— §2.4 说"02c 只画了市场/兵营"，实际代码里
   `market.maxLevel = 1`、五座兵营的 3 级只有数值没有外观。两条链补图时**直接用本批的量法**。
2. **plot 场景不存在**（§2.3）。塔图现在只在描述浮层里；真做场景时这批图搬到 plot 上。
3. V1 试玩若在 S5 之前跑，记录里仍要注明"建筑只有数字，外形只在描述里"（§9.3 的原话）。
4. 四族材质只做了"换调色板 + 门/窗材质"，没有做族特异母题（如 p3 的藤蔓、p2 的熔岩裂纹）。
   44px 下再加母题会吃掉塔身结构，**建议不做**，要做得先加画布。

## 8. 事后订正（B1 批，2026-11-13 晚）

**p2（熔岩黑铁）的调色板在 B1 批被调亮了一档**，原因不在行会本身：行会这 12 帧与
B1 的 52 帧共用 `guildPaletteOf()`，而 p2 的平均亮度 L\* 26 放在城镇卡片底色
（`#33240f`，L\* 15.5）上是一团深棕 —— Δ10.5，低于项目约定的 18。

| | 改前 | 改后 |
|---|---|---|
| p2 平均 L\* | 26 | **33**（Δ17.3） |
| p2 木件 | 暖棕 | **冷灰** `#6b5a50`/`#4a3b33`（这一族的木头是包铁的） |
| 跨族 Δrgb（最接近的一对） | 13.2 | **19.5** |

⚠️ 只调亮不够：会把 p2 推到 p3 旁边（Δ 掉到 13.2，判据 12），所以木件必须同时换色相。
