>
> **与 `art-overhaul-options-2026-10-22.md` 的关系（两份不冲突，是不同层）**：
> 那份回答「要不要换字体/换资产、多少钱」——管的是**观感上限**（换赛道）；

## 1. 结论

「图像粗糙 + 全是 text box」不是美术资源不足，是**界面只有一套语法**，并且这套语法在三个维度上都落到了下限：

1. **字太小**：全站 102 条 `font-size` 里，61 条（60%）≤12px，最多的是 12px（33 条）、其次 11px（19 条）、10px（8 条）。最大的一档正文只有 15px，且用得非常少。
2. **没有材质层级**：菜单、城镇、英雄栏、战斗侧栏、结算框，全部是「深棕底 + 1px 金棕描边 + 圆角 3~6px」。层级只能靠尺寸区分 ⇒ 大框只是"更大的框"。
3. **触屏没有反馈**：2,738 行 CSS 里 `:active` 只有 **1 条**，还落在战斗回合胶囊上（`.bt-chip:active`，`style.css:1391`）。所有 `.btn` 只有 `:hover` —— 手机上永不触发。按下去什么都没发生，这就是"不流畅"最直接的来源。

外加一处真实布局 bug：**英雄栏数值互相压字**（`.hp-bar-top` 在 87px 半宽格里 `nowrap` + `space-between`，四位数移动力直接溢出压到隔壁"法力"上），和一处**内容溢出**（城镇面板 `scrollHeight 270 / clientHeight 162`）。

## 4. 设计 token 提案（可直接抄）

```css
:root{
  /* 新增 3 个，其余 12 个不动 */
  --parch-bg:#f3e6c6;  --parch-ink:#3a2a12;  --press:rgba(0,0,0,.45);

  --t-display:28px; --t-h:20px; --t-body:15px; --t-cap:12px;   /* 只留四档 */
  --lh-body:1.45;
}

/* 三层材质 */
.mat-oak{                       /* 主菜单 / 城镇 / 大弹窗 */
  background:linear-gradient(180deg,rgba(255,236,190,.055),transparent 38%),
             linear-gradient(180deg,#2a1d10,#1d1409);
  border:1px solid #0c0803;
  box-shadow:inset 0 1px 0 rgba(255,226,168,.22), inset 0 -2px 0 rgba(0,0,0,.45);
}
.mat-parch{                     /* 阅读区：英雄属性 / 建筑描述 / 结算 —— 现在一块都没有 */
  background:linear-gradient(180deg,#f3e6c6,#e0cca4);
  border:1px solid #b9a273; color:var(--parch-ink);
  box-shadow:inset 0 0 0 1px rgba(255,255,255,.55);
}
.mat-iron{                      /* HUD 读数 / 回合胶囊 / 浮层 */
  background:rgba(12,8,3,.62);
  border:1px solid rgba(255,232,170,.16);
  backdrop-filter:blur(8px);
}

/* 全站按压 */
.btn:active, .menu-item:active, .iconbtn:active,
.town-tabs .btn:active, .rail button:active, .act:active{
  transform:translateY(1px) scale(.985);
  filter:brightness(.92);
  transition:transform 120ms ease, filter 120ms ease;
}
```

**关键判断**：深底浅字适合短标签，超过两行的说明文字在深棕上会糊成一团。把「英雄属性 / 建筑描述 / 结算」翻成羊皮纸（深字浅底），是这一次改动里"最不像同一个游戏"的一刀，也是最省事的层级来源。

## 5. 渲染三改（不加一张图）

项目零位图全程序化，所以"换美术"不现实，但粗糙感有三个纯算法来源：

1. **32px 硬边瓦片** —— 草地贴沙地是一条直线。改法：按 4 邻域在交界内侧 12~20px 拉一道**邻色渐变**（`createLinearGradient` + 邻色 alpha 0.5→0），交界从此不再是"色块拼接"。判据：沿交界采样相邻像素色差，硬边样本 ΔL 集中在一个像素上，加过渡带后应摊到 ≥3 像素。
2. **物件没有接地影** —— 树像贴纸浮着。改法：绘制前先画 `scale(1,0.32)` 的径向黑影（alpha .45→0），再统一 2.4px 深色外描边 + 左侧 1px 暖白高光。判据：影子覆盖率 = 物件数（现在 = 0）。
3. **可达范围整格填色** —— 与地形同质，被读成"这块地是青色的"。改法：格心点阵 + 边缘亮带。

三改都在 `render/MapRenderer.ts`，其中**接地影是最小改动、最大观感**，建议先做。
