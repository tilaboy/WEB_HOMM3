## 3. 两条尺子必须分家（本轮最大的结构改动）

`asset-spec §5.6.2` 的 **T1→T5 体量阶梯**（62/70/78/88/100%）与 `spec §15.2` 的**体形五档**不同构：

> p1 的鹰是 T3、骑士是 T4，但鹰（h=1.22）必须**比骑士（h=1.04）高** —— 因为骑士占的是**宽体**档，用宽度换高度。

把两套塞进同一条闸只会互相判红，而且那种红说明不了画错。现在：

- `frameTargetFinalHeight()` 是**唯一分叉点**（`unitArt.ts`），缩放/居中/底锚代码两套共用；
- `b0audit` 的 H1/H2/S1 跳过 `BODY_PLAN` 收录的兵，`audit:b0` 的断言 12（横向溢出复算）也改成 import 同一个函数；
- **不重不漏**由 `audit:bodyplan [0b]` 闭合（体形档 ⊆ 已登记族，且族内 5/5 全切）。

## 4. 配色纪律：只许用 `B0_PALETTE` 的字面值

第一版自己造了 18 个色（`#2f5686` / `#f2c14e` / `#e8bd92` …），`audit:b0` 的断言 2 **15 帧全红**，而且那正是 §3.4 明令禁止的事。改成按材质族取字面档之后，真正的难点是**断言 8**（相邻异族材质 ΔL\* ≥8，色相接近时 ≥12）—— 而色板在 **66~74 这个区间挤了 8 个色**（p1wall0 69.3 / metal2 73.5 / skin2 72.2 / canvas2 66.9 / stone2 66.3 …）。

踩过的 7 组撞色，逐条记下来给 S3b 复用：

| 撞色 | ΔL\* | 现场 | 解法 |
|---|---|---|---|
| `skin4 #f0c79a` ↔ `p1accent4 #8ecdf8` | 3.0 | 小孩手臂 ↔ 袍上光条 | 肤降到 **skin2**，光条改布暗 |
| `canvas4` ↔ `metal4` | 4.2 | 弩托金线 ↔ 钢矢 | 金件全降 **canvas2**；矢用钢浅 |
| `clothDark` ↔ `wood0` | 6.6 | 裤 ↔ 靴 | 靴改 **ink0**（最暗，对谁都够） |
| `p1clash` ↔ `canvas2` | 10.6（同色相需 12） | 鹰喙 ↔ 爪 | 爪与喙下暗点改**羽暗** |
| `white(p1wall2)` ↔ `metal4` | 0.7 | 白袍 ↔ 剑刃 | 剑刃降 **metal0**，剑柄用木暗 |
| `white(p1wall2)` ↔ `canvas4` | 3.6 | 白袍 ↔ 腰带 | 腰带改**木暗** |
| `metal2` ↔ `skin2` | 1.3 | 头盔檐 ↔ 脸 | 头盔檐升 **metal4** |

**可复用的两条经验**：

1. **每个族只挑 5~6 个色**，且彼此至少差 15 个 L\*；同族的三档天然豁免（断言 8 不看同族）。
2. **浅档只留给「周围没有别的东西」的部位**。凡是会和别的材质贴边的（腰带、系带、剑柄、弦），一律用最暗档（`ink0` / `wood0`）——它们对任何邻居都 ≥19。

## 5. 8× 目检改掉的八处（机检看不出来的）

前四处是首版 8× 实拍发现的，后四处是**表情闸红了之后**顺着查出来的：

| 现象 | 改法 |
|---|---|
| 小孩的脸被头发盖住（一条 1.0~1.25hr 的横带正好压在眼上）⇒ 22px 下是「戴帽子的蓝人」 | 头发只盖颅顶（0~0.38hr），发际线以上不再压眼 |
| 十字弩读成「抱着一块木板」（0.62h 的托 + 贴在最左端的弓臂） | 托缩到 0.30h 并**整体外移**到躯干之外（原来横跨整个胸口 ⇒ 一眼是棕色方块）；竖弓两端**向前**折、弦收成 V；矢只出现在出手帧（常驻的话竖弓 + 横矢凑成十字架） |
| 骑士的骑手 / 马鞍 / 马背连成一整块蓝砖 | 马铠下移 0.04h（露出白马背）+ 改**钢甲** |
| 天使的远翼是深灰板、像披风 | 两翼同用白，靠羽骨（metal0）+ 内侧一道 p1wall0 分缝（见下 §5b 第 4 条） |
| **五张脸全红**：`audit:expr` 报「眼对数 = 0（候选 0 块）」 | 1px 眼点 → `h3Face()` 的 2×2（**右上角 hi0**）+ 眼下 3 行的嘴线；鹰按侧脸记 profile |
| 骑士的**左眼被长枪杆涂掉**（枪是 `dy/dx≈0.13` 的浅斜线，2px 粗 ⇒ 每行横跨 8~10px，第 18 行整段铺木色） | 枪改到**骑手之前**画（头/肩/胸把它挡在背后）；顺手删掉同样压眼的蓝白枪旗 |
| 天使**头顶被裁平、光环整圈在画布外**（`bb = base − 0.04h` 当基准，h 全给了身体 ⇒ 顶在 y=−1，环在 y≈−5） | 改成**自上而下**排：`topY = base − h` 起算，光环占最上 2·ry，再留 3px 描边缝放头 |
| 天使**翼尖在 y≈−18**，被裁成两根竖板（读成犄角） | 翼高改成「抬到头顶略下」（`wH = wY − headTop`），宽 0.40h（归一化放大 1.1 倍后仍 ≤64） |

## 5b. 表情闸为什么值得留着

`audit:expr` 这轮抓到的是**真的画错**，不是尺子挑刺 —— 但它红的方式很像尺子问题（"五张全红 ⇒ 大概是判据太严"）。三条经验：

1. **不变量先查"有没有被别的东西盖住"**。骑士的左眼不是画错位置，是被枪杆覆盖了一整行。
   眼点在源码里是对的，像素上没了。这类错只有**按像素读**才看得见。
2. **`2×2 + 右上角 hi0` 是硬签名**，不能"差不多"：1px 点、高光居中、高光在左上都不认。
   理由在 `tp8exprtest.mjs` 的头注释里：这条签名同时守住 §1.4「唯一高光只此一处」。
3. **归一化会吃掉 1~3 行**（`targetBody = targetFinal − 1`，且从 bbox 顶部往下删）。
   所以脸必须离剪影顶部足够远，且**别在脸上压任何"后画的"东西**（旗、剑、枪、披风）。
   本轮三处翻车（枪旗、枪杆、白缨）全是后者。

例外表 `FACE_LAW` 只加了一行：`cu_p1_eagle → profile`（侧向钩喙 + 单眼 = 侧脸的定义，与独角兽同一条理由）。
三档帧数因此从 13/6/1 变成 **12/6/2** —— 算式写在常量注释里（20 − 6 − 2 = 12），不是"放宽"。

## 7. S3b 的起手清单

1. 先定 5 个 `h`，让它们落进五个**不同**的档（宽体那条靠 `w ≥ 1.35h`，别再靠高度）；
2. 从 `B0_PALETTE` 里挑色，每个材质族最多 2 档，**避开 66~74 区间**；
3. 先跑 `audit:bodyplan` 看档位与剪影，再跑 `audit:b0` 看调色板与明度；
4. `--png` 出图，8× 目检过一遍再提交（机检全绿不等于「像」）。
