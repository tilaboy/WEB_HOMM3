## 3. 三次"1px 陷阱"（本批的主线）

这一批五件东西里有**三件是 1px 级别的小件**，三次都栽在同一件事上：**后置描边（outline）会吃掉 1px**。

### 3.1 骷髅的盾：圆 → 正方形 → 鸢形

| 版本 | 画法 | ×12 实拍读成 |
|---|---|---|
| ① | 正圆 `ell`（iron 盘 + 1px ink 边） | **肩上挂了颗灰气球** —— 圆盘 + 平涂灰没有任何指向性 |
| ② | 圆 + 中线一道 `ironLite` 竖脊（宽 0.55·shw） | 好一点，但竖脊太宽，读成**一块亮方块压在胸口**，且盖掉整排肋骨 |
| ③ | **平顶 + 收底尖的鸢形** + 顶沿亮边 + 中线窄脊（0.35·shw） | **盾** —— 平顶是盾与球/石头的分界，三角底是盾的专属剪影 |

顺带：盾的位置从"中线 0.42 处"下移到 **0.55 处**、半宽 0.115h→0.10h，
让上排肋骨露出来 —— 盾是"挂在左臂上"，不是"贴在胸口"。

### 3.2 腐尸的右手：三版，全部死在"1px 手指"

| 版本 | 画法 | ×12 实拍读成 |
|---|---|---|
| ① | 三指摆在腕**外侧**（`handX2+0.03h` 起，间距 2px） | **三条悬空的竖线（速度线）** —— 指尖离臂远，下面全是背景，描边把每根指各圈一圈 |
| ② | 照左臂镜像：腕块 `[+1,+2]`、三指落在 `+3/+1/−1` | 手指被描边逐根圈死；腕块与臂端之间还留了一列空隙 ⇒ **手上掉了一块砖** |
| ③ | **不画手指**：末端一块 4×5 的**垂掌** | **下垂的手** —— "下垂"这个方向本身就是"伸出的手"的语言，而且 4×5 的体块能被描边完整包住 |

结论（写进注释）：**43×37 上，1px 部件要么被描边吃掉，要么被描边切成独立小件。**
能活下来的是**≥3px 的体块**和**方向**，不是细节。

### 3.3 伯爵的立领：披肩 → 披肩 → 立领

| 版本 | 画法 | ×12 实拍读成 |
|---|---|---|
| ① | 四顶点领片，下缘拉到 `sleeveW + 0.02h`，亮紫 | **亮紫披肩 / 肩垫**（横向一宽就变成"肩"） |
| ② | 三角形刀片，底点收到 `0.95·sleeveW` | **更大的一块亮披肩**（底点还是按肩宽算的） |
| ③ | **贴颅侧的两根窄刀**（宽 0.05h ≈ 2px，从下颌竖到 `hy−0.85hr`） | **立领** —— 竖直线段是"领"，横向块面是"肩" |

同时把"外中点"这个顶点删掉：留它会让领片下缘鼓出去，和同样 `plum` 的**翼尖连成一片**（两个形状同色相邻就并成一个）。
现在领（窄刀）与翼（外侧尖）之间隔着 2px 暗斗篷，读成两件东西。

  2. **甲形不能是矩形** —— 直角块在 ×12 上读成"胸前一页灰纸 / 围嘴"。

> ⚠️ 兵牌（43×37）上墨边只能 1px（2px 会把整块 iron 吃光），所以 `bx = card ? 1 : max(2,…)`。

## 5. 一个浪费了 40 分钟的环境坑（本次记进 GATES）

改完 `src/render/unitBodyPlan.ts` 直接跑 `npm run -s audit:b0`，**读数一点没变**，
以为是"改了没生效"，又去改形状 —— 实际是 **`tools/b0audit.mjs` 读的是 `dist/`**（`tools/_dist.mjs`），
`src` 改动没有编译进 `dist` 就等于没改。

```
npm run -s build && npm run -s audit:b0
```

**通则：任何 `tools/*.mjs` 的读数，前提是刚跑过 `npm run -s build`。**
判断"是不是没生效"的最快办法：看读数有没有连小数位都不动 —— 逐位相同先当故障查（铁律 9 同款）。
