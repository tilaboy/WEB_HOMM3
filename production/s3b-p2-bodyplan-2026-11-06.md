## 3. 五张五个骨架，不是一个人换五套衣服

这是 p2 和 p1 最大的差别。p1 五兵共用「人形 + 配件」（大头小孩 / 横弩 / 骑士 / 收翼鹰 / 光环天使），
所以只要配件够显眼就能分开。p2 如果照抄这个思路会立刻翻车 —— **它的两两之间连骨架都不同**：

| 兵 | 骨架 | 唯一的识别点（22×30 下还剩的那一处） |
|---|---|---|
| matchman | 细棍人形（四肢 2px） | 头顶火苗 + X 形张开的手臂 |
| bronze | 构装方块（宽肩收腿） | 左侧外伸的方锤 + 两点金眼 |
| threewolf | 四足横身 | **三个错落的头**（0.16h 高差）+ 蓬松尾 |
| lavagiant | 沙漏躯干（细腰分腿） | 肩刺 + 2px 熔岩裂缝 |
| devil | 有翼人形 | **下掠**翼 + 双角（与天使上掠成镜像） |

翅膀朝向是全表第二层区分（§16.1）：**天使上掠 / 恶魔与绿龙下掠 / 鹰收翼**。
本轮把恶魔的翼尖压到 `base − 0.1h`（几乎到脚），宽度 0.44h —— 远看是一片垂下来的黑膜，
近看才见骨节。这是唯一一处「宁可牺牲细节也要保住剪影方向」的地方。

## 4. 配色纪律：撞色从 7 组降到 5 组，但都在同一处

S3a 记的两条经验（每族 5~6 色、浅档只给孤立部位）直接用上了，所以**第一版就没超范围**。
真正花时间的是断言 8（相邻异族材质 ΔL\* ≥8，色相 <30° 时 ≥12）：

| 撞色 | ΔL\* | 现场 | 解法 |
|---|---|---|---|
| `wallDark #8a5a30` ↔ `red #e04a34` | 10.3（同色相需 12） | 火柴人的四肢 ↔ 短裤 | 新开 `limb #5f4022`（对红 **18.7**），四肢与铜人暗面共用 |
| `bronze #b9a06a` ↔ `metal2 #aab6c2` | 6.6（两者都在 L≈70） | 铜人躯干 ↔ 锤头 | 锤头改 `bronzeLite`（**同 canvas 族 ⇒ 豁免**） |
| `metal0 #6b7686` ↔ `wallDark #8a5a30` | 6.6 | 铜人面甲缝 ↔ 挂带 | 挂带改 `limb`，面甲缝保留（它必须够暗才像缝） |
| `bronzeLite` ↔ `glow #ffd06a` | 1.1 | 铜人头顶高光 ↔ 眼 | 高光降 `metal0`；`glow` 是唯一允许贴着脸的亮色 |
| `stoneDark #6f6858` ↔ `wallDark` | 8.9 | 巨人嘴线 ↔ 身上的皮革 | 皮革撤掉（巨人全身石材 + 熔岩，本来就不该有皮革） |

两条**新的**、S3a 没遇到的经验：

1. **构装类最容易撞色**。铜人身上同时有「金属 / 铜 / 发光」三种材质族，而色板在这三个族里
   各只有一个中明度档位可用 ⇒ 必须先排「谁挨着谁」，再选色，不能先选色。
2. **「脸缝」不能用 ink0**。铜人的面甲缝第一版用 `#2a1a12`，`audit:expr` 立刻把它当成嘴
   （3px 宽、离眼 3 行）—— 改成 `metal0`（ΔL 只差 1 档，但 **不是 ink**）后，表情闸读的是
   `glow` 通道、嘴从 `optional` 变 `none`。**五官之外的黑线一律不许超过 2px。**

## 5. 8× 目检改掉的（机检全绿但读不成的东西）

这一批的 8× 目检比 p1 更重要，因为**跨度大的族在 22px 下会丢掉两头**：

| 现象 | 改法 |
|---|---|
| 火柴人只剩「一个黑圆头 + 一点红」——1px 四肢在 22px 下整根消失 | `limbW` 下限 **1px → 2px**（`Math.max(2, round(h*0.065))`）；代价是它看起来比「火柴」粗，但 22px 下先要能看见 |
| 熔岩巨人是「一块没有手臂的红方块」 | 手臂从 `redDark` 改**亮红 `red`**（暗红贴暗暗的躯干完全融合）；宽度不变 |
| 三头狼第一轮读成**长颈鹿**（脖子 8px 高、身体只有 4px 厚） | 身体厚 `0.115h → 0.16h`；脖子压短；腿加粗；尾巴改蓬松 |
| 三头狼第二轮读成「一只鬃毛狮子」 | 头间距 `0.18h → 0.22h`，半径收到 0.068h / 0.075h |
| 三头狼第三轮仍挤成一团 | `wallDark` 暗缝 + 三头高度错落 0.16h + 吻缩短到 1.5r + 耳加高到 1.75r |

**三头狼是这批唯一改了四轮的。** 前两轮的问题都不是「画错」，是**读法被牵着走**：
- 脖子长 ⇒ 大脑自动归到「长颈动物」（长颈鹿）；
- 头挨太近 + 身体短 ⇒ 归到「一圈鬃毛」（狮子）。
两次都是**改对了一个部位、又暴露出下一个误读**。真正的解法是第三轮才找到的：
**暗缝 + 高度错落 + 颈桥**同时上 —— 前两个给出「三个独立的头」，颈桥保证它们仍是一个整体
（不是三只小动物并排）。

## 5b. 表情闸这轮抓到的是一个「设计意图」被描边改写了

`audit:expr` 报三头狼 `嘴 ΔE=15.5（#2a1a12↔#000000）`。嘴本身没画，是**误判**。
顺着查下去：

- 三个头之间留了 1px 透明缝（有意为之，让三个头分开）；
- `buildB0Frame(...)` 的描边 pass 把这条缝**灌成 3px 的 ink0 带**；
- 其中一段（row 31, x 21..23）正好落在「左眼右侧」的嘴搜索窗口里，而它**右边是透明的**；
- `[Contr]` 拿透明度算 `#000000` ⇒ 这条缝对左邻是墙、对右邻是黑，ΔE 15.5 < 20。

修法是两处，都要：
1. 主头的眼从 `−0.2r` 挪到 `−0.55r`，让窗口里的行落在头/颈上；
2. 加**颈桥**（`0.56h × 0.12h` 的 `wall` 矩形），三个头连成一团，缝不再通向外部。

只做第 1 条时 row 31 仍有一段 — 因为描边灌进来的长度取决于缝的位置，不取决于眼的位置。
**教训：描边是最后一道工序，它会把"设计上的空隙"改写成"画上的墨"。任何靠留白表达的
分隔，在检查器眼里都是实心黑。**

## 7. S3c 的起手清单（p3 翠林五兵）

1. **宽体档归树人还是猿人**先定死：§15.2 给的是「矮=矮人 / 中=丛林射手 / 高=树人 / 宽体=猿人 / 巨物飞行=绿龙」，
   但树人 h=1.22 与绿龙同高的话，两者只能靠**翼展**分 —— 先量一遍再画。
2. 绿龙的翼是**下掠**（跟恶魔同向），所以 p3 内部没有「上掠 vs 下掠」的对照可用，
   它必须靠**长颈 + 尾**和恶魔分开（同族内则靠体型）。
3. 族色是翠林绿，与 `p2clash #2fbfa0` 同色相 ⇒ 先查断言 8 的 ≥12 那条，别等红了再回头。
4. 其余照 S3b：先档位、再调色、再 8× 目检，机检全绿不等于「像」。
