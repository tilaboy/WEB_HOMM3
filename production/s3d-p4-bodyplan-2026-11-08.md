### 4.1 全量回归抓到的两处「尺子自己在抖」（已修，都不是 S3d 的回归）

54 门里 **53 绿、`probe:pathday` 红**，红在 `pathday-dash`（今天实线 / 明天虚线）：

| 臂 | 今天中点 | 明天中点 | 读数 |
|---|---|---|---|
| 第一次 | 6 枚（空 0） | 9 枚（空 **1**） | ❌ 门槛 `ceil(9×0.2)=2` |
| 复跑 A | 6 枚（空 0） | 9 枚（空 **3**） | ✅ |
| 复跑 B | 6 枚（空 0） | 9 枚（空 **1**） | ❌ |

**根因不是画错了，是尺子在随机抽样**：虚线相位按墙上时间推进（`MapRenderer.flowPhase`，
`devflowphase` / `devflow` 两个开关早就存在，只是这个门没用它们），而判据量的是
"明天段中点上有没有笔触" ⇒ **等于抓一帧**。同一 seed 下留空数在 1~4 之间跳。

**修法**：门里默认钉 `&devflowphase=0.5`（半个虚线周期 = 3.6 世界 px），
连跑三次全读到 **4/9**。**门槛、几何、配色一个字没动**，只把"抓哪一帧"从墙上时间换成常数；
虚线在流动这件事另有 `probe:pathflow` 单独把关，`--selfcheck` 的 `ctl-flip` 六条仍全红。

> 记这条是因为它长得像功能回归：`pathday` 属于"我这次根本没碰"的模块（S3d 只动
> `unitArt/unitBodyPlan/unitFrames` + 美术工具）。**先证是不是尺子，再证代码**（铁律 22 的同类）。

**第二处：`audit:haloflip` 本底被撑到 1129 块**（第一遍全量回归的另一条红）。

`haloflip` 的四臂是"同 URL 抓两次"作安慰剂来量噪声本底，实测本该 **0–28 块**；那一次读到
**1129 块**（12.6% 画布）⇒ ② 的阈值按 `10×本底` 被撑到 `11290`，而信号只有 553 ⇒ 假红。
单跑三次本底 **0 / 18 / 20**、信号 **541 / 546 / 531**，全绿 —— 即"机器被别的东西占满时
四次导航没落在同一状态"，与代码无关。

修法不是放宽阈值（那会让"回退被吞"也能绿），而是**加一条本底合理性闸**：

```js
const BASELINE_MAX = 200;           // 块 ≈ 2.2%（分母 8940），实测本底 0–28 的 7 倍余量
if (floor > BASELINE_MAX) { /* FAIL：本次读数作废（四次导航不在同一状态），重跑；连续复现再查代码 */ }
```

即：**污染要大声失败**，不能伪装成 ①② 的结论。加闸后全量回归 54/54 一次跑完，
`pathday` 与 `haloflip` 都在其中（说明两处修复在负载下也成立）。

## 5. 目检（本批的**主要成本**，四个门一次都没抓到）

`audit:b0` 只证"合法"（档位、色差、眼嘴够不够对比），`probe:card` 只证"没被拉伸"。下面这些**全部是 ×12/×16 单张 + 逐像素 ASCII 才看出来的**，一共返工 **五次**：

| 兵 | 读错成什么 | 根因 | 修法 |
|---|---|---|---|
| 骷髅 | 米色小人 / 深色条纹上衣 | ① 胸腔是一整块骨；② 改"暗腔 + 骨条"后**暗面积大于骨**，22px 下读成条纹衫 | **骨为主体 + 1px 暗缝且不碰外缘**；删掉竖脊柱（它把缝全堵了） |
| 僵尸 | 金发 / 创可贴 / 健康人 | ① 头顶一块骨被读成头发；② 米色补丁被读成围兜 | 深色破衣 + 破衣上**两道 1px 骨白横线**；下颌与颅之间留 ink 开口 |
| 吸血鬼 | 猫耳 → 灯罩帽 → 泡泡袖 → 葡萄串 | 立领两次、翼三次都改错：竖尖=猫耳、整块梯形=灯罩、三扇贝=葡萄 | **立领到耳际夹住脸**（与斗篷同色）+ **翼只露两个尖**（0.10h）+ 去掉斗篷中央的深色圣带 |
| 牛头怪 | 稻草人 / 十字架 / 肉饼 | ① 水平通栏肩 + 两手同高；② 斧柄用 `ink`（深底看不见）⇒ 斧头浮空；③ 肩给到 0.60h ⇒ 一团肉 | 窄躯干 ±0.28h + **肩横板** ±0.46h + 左臂外垂带拳 + **柄竖直立在体侧**（外露，不被躯干压掉） |
| 摄魂怪 | 两条腿（对称深 V）/ 站在地上的裙摆 | ① 深 V 锯齿读腿；② 浅扇贝让它落到地面 | 4 条**长短不齐**的垂布（0.16h~0.38h）+ 外侧两角切高 |

**两条通则**（写给下一批）：
1. **暗色缝不是边界，透空缝才是** —— 后置 1px 描边会把 1px 的暗缝灌成墨，只有背景透空才读得出"分开"。
2. **兵牌必须按目标像素高单独设计一遍** —— 骷髅的兵牌只有 **13px 高**（cu 帧是 24px），同一套比例搬下来时 `Math.max(2,…)` 的地板会把 3px 的躯干撑成 7px、把 1px 的腿整根吃掉。
