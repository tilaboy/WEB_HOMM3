## 2. ★ ② (e) 的预期结果：**「看不出变化」—— 这不是失败，这正是它的用途**

**(e) 不是拿来选的，是拿来「证伪」的。** 它要回答的是：

> 「把现在的像素**存成图片文件**」这件事，本身会不会让画面变好？

**答案：不会。** 本档实测（`cu_p1_lampbearer`，64×56）：

| | 结果 |
|---|---|
| 逐像素 **平均 \|ΔL\*\|** | **0.000** |
| **最大 ΔL\*** | **0.0** |
| **变化像素占比** | **0.0%** |
| 体积代价 | 0 B → 356 B（PNG-8，18 色） |

分辨率没变 ⇒ 能装的像素数没变 ⇒ **「画质提升」按定义 ≈ 0**。

> ⚠️ **报告纪律（team-lead 点名）**：**(e) 的结论只能写成「看不出变化」，不许包装成「提升」。**
> 谁把 (e) 说成"换了位图就有改善"，就是把「证伪实验」当成了「成绩单」。

**附注（同尺寸、换来源）**：把仓里**已排除**的 `ai-drafts` 弓手草稿按它自己的真像素尺寸（`k=16`）降到 64×56 后，
**观感并不比程序化更好**（并且右下角还留着**平台水印残余**）。⇒ **换来源也买不到画质，还多带一笔来源面代价。**
（两张是**不同的画**，所以**不给"谁更差"的 Δ 数** —— 那个数没有意义，看观感即可。）

## 4. ① (b) `crestL_p1` —— 7 步管线实况（数全部实测）

出图：`assets/ai-drafts/pixel_art_full_body_character__2026-09-21T02-39-02.png`（1024×1536，AI，1 张 ≈ 5–10 credits）

| 步 | 做什么 | 实测 |
|---|---|---|
| [0] | 出图 | 1024×1536（`asset-spec §5.3` 参数模板；底色要求纯洋红） |
| [1a] | **掩平台水印角落**（x≥82%, y≥92%） | 该区非透明像素 **22,755 → 0** |
| [1] | 抠底（**必须在降采样之前**，§5.2①） | 自动识别底色 `#ab2670`；键掉 **1,024,712 px**；原图残留粉 **21 px** |
| [2] | **块众数**降采样 8:1（**不用 nearest / bilinear**） | 128×192（钳色前 **6,787 色**） |
| [3] | 调色板钳制 + 色数收敛 | 6,787 → 钳到色板 **39 色** → 收敛 **24 色**（`§3.4` 上限 24） |
| [4] | 裁剪 → **整数比**缩放 → 落位 | bbox 90×156 → **×2** = 180×312 → 落位 256×384（dx=38, dy=72，水平居中 + 底部基线对齐） |
| [5] | **描边重建**（丢掉 AI 自带的边，重跑 `ink0`） | 2px（`§1.1`：高 ≥65px 用 2px） |
| — | **[6] 手工修** | ❌ **未做**（无画师）—— 见 §6 |
| [7] | PNG-8 ≤32 色 | **5,704 B · 24 色**（实际用 23） |

**成品合规（`asset-spec §3.3`）**：color type 3 / bit depth 8 / 非交错；PLTE 24（≤32）；
tRNS 只含 `0|255`（**无半透明**）；5,704 B（`crestL_*` 放宽到 ≤24 KB）；洋红残留 **0 px**。

> 另有一个**独立实例**（同 git 身份、多实例）在 `assets/bitmap-proof/figs/verify_report.json` 里
> **独立复核了本档这张成品**（尺寸 / 色数 / 字节 / 水印区 / Δ），结论**逐条 PASS** —— 这是互证，不是自证。

## 7. 我的结论（供用户拍板用）

1. **(b) 成立**：门面是程序化的**真实短板**，位图在这里**有真实增益**，且**可回退**（不碰地图 / 战斗）。
2. **(e) 证伪成功**：**「把像素存成文件」不等于「画面变好」** ⇒ 用户说的"感觉不到提升"，**瓶颈不在介质**，在**尺寸 / 内容量 / 构图**。
3. **但 (b) 现在卡在"来源面"**：本环境 AI 出图**带水印、不可直接商用** ⇒ 要真做 (b)，得先解决**"图从哪来"**（授权 / 外包 / 无此限制的通道）。
   **这一条是花钱与法务决策，不是技术决策** ⇒ 归用户。
4. **不要**把本产出读成"画面升级已完成"。它只回答了**一个**问题：**位图值不值当门面**。
