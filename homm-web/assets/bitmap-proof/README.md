## ★ ④ 诚实预期说明（**这一节别跳**）

1. **(e) 的预期结果就是"看不出变化"，而这正是它的目的。**
   它**不是**一次画质升级的演示。若把它读成"加了贴图所以变好了"，就读反了 ——
   它证明的是「**换介质不产生画质**」：同分辨率下位图能装的像素数 = 程序化能装的像素数，**一个像素都不会多**。
   实测：3 帧逐像素 **Δ = 0.00**，代价只有体积（3 帧合计 **1063 B**）。
   ⇒ **不把 (e) 包装成"提升"。** 它是一条**证伪**。

2. **(b) 这一张的预期是"第一眼确实不一样了"**，但请同时记住三件事：
   - 它是**新位置**（现在那里什么都没有），**不是"把旧的换掉"**；
   - 它是 **AI 生成 + 管线加工**，而管线**步骤 [6]「手工修」没做**（本项目零画师）⇒ 精细度还会被真人拉高一截，也就是说**这张甚至没到它的天花板**；
   - **本环境的 AI 出图自带平台水印** ⇒ 按你定的硬边界「交付位图必须无水印 + 明确可商用」，**今天这条不达标**（见下「要裁的两条」）。

3. **不要用这两张图去推断 (c)/(d)。**
   一个证明"大尺寸门面有新东西"，一个证明"同尺寸换介质是零" —— **都没有测过**地形 / 单位位图化之后的表现。
   而 `§3.1` / `§3.3` 已经给出"**没增益、甚至会因非整数 zoom 劣化**"的理由。

4. **本页没有一条数字是"把算式当实测报"。**
   每个数都有脚本 + 原始命令，读的是**落盘文件**，不是内存中间态：
   - (b)：`assets/_pipeline/run.mjs` → `out/metrics.json`（对方产出）；**独立验收** = `assets/bitmap-proof/pipeline/verify-others.mjs`
   - (e)：`assets/bitmap-proof/pipeline/e-equal-size.mjs` → `figs/e_report.json`
   - ③：`assets/bitmap-proof/pipeline/startscreen.mjs` → `figs/shots_report.json`（真 Chrome 实拍）
   - **构建绑定**：全部读数绑 `dist/main.js` md5 `ff653bcec69f8616e1b7b5b4bff226c6`。

5. **交付时点**：这份东西先压着。等新包装到手机上、亲手玩一眼，再回来看 (b)/(e)。

## 要 team-lead / 用户裁的两条（执行者不该自行决定）

1. **水印与商用性**：本环境 AI 出图**自带** `AI生成 WORKBUDDY` 水印。现做法是**把右下角纯背景区整片掩掉**（掩后该区不透明像素 22755 → 0），水印像素确实没了；
   但那是"**在输出侧去掉水印**"，不是"生成侧就没有水印"，而且**谁生成的 / 条款允许什么 / 能不能商用仍然未知**。
   ⇒ 按硬边界「**明确可商用**」，**(b) 经 AI 这条路今天不成立**。要么换一个**明确授予商用**的模型/服务，要么先认定"门面图必须外包 / 找画师"。
2. **`crestL_*` 落地后放哪**：当前构建**没有"选族页"**（`StartScreen.ts` 无阵营选择 UI）⇒ ③ 的"改后"是**运行时注入的示意**（未改源码）。
   真要落地要改 `src/**`（本轮明令不动）。另外真机口径（792×320）下立绘只能放 **0.5×**，要 1:1 就得给它一列 / 一页。

## 副产品：`asset-spec §5` 的两个缺口（建议回填规格）

本条来自**第二条独立实现**的交叉验证（同原稿：本档 **5724 B / 23 色** vs 对方 **5704 B / 24 色** ⇒ 管线可复现）：

1. **§5 的 7 步里没有"色数收敛"这一步。** 只做 §5.2③ 的"钳到色板"，实测留下 **40 色** —— 直接撞 `§3.3` 的 ≤32 上限（第一次跑就抛 `索引色超上限：>32 色`），更超 `§3.4` 的每精灵 ≤24。
   ⇒ 必须补一步"按用量收敛到 ≤24（给 `ink0` 留 1 色）"。
2. **§5 里没有"掩掉 AI 自带的水印 / 杂字"这一步。** 水印是浅灰字、离洋红很远 ⇒ **抠底带不走它**，会被钳成 `ink0` 留在右下角。
   实测：未掩的交叉验证版右下角（x≥82%, y≥92%）**365 个不透明像素、全是 `#2a1a12`**；做了掩除的版本 **0**。⇒ 这一步不是可选的 —— 但它**掩的是像素、不是许可**（见上「要裁的两条」）。
